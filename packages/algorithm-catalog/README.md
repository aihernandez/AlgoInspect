# Algorithm catalog

Fuente compartida de contenido determinista para la fase web.

- `src/catalog.js`: metadatos, lenguajes e implementaciones mostradas.
- `src/traces.js`: trazas paso a paso reconocidas.
- `src/theory-content.js`: contenido teórico estructurado.
- `src/readme-content.js`: documentación detallada por algoritmo.
- `content`: implementaciones, escenarios y pruebas que respaldan ejemplos concretos.

El catálogo no analiza código arbitrario. Su responsabilidad es proporcionar ejemplos y evidencia reproducible.
