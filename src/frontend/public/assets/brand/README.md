# AlgoInspect brand

The official provisional direction is concept **07, Evidence nodes**. The exploratory source is preserved in the external project archive.

## Production assets

- `algo-inspect-mark.svg`: transparent symbol for product headers and compact placements.
- `algo-inspect-app-icon.svg`: square source for application and browser icons.
- `algo-inspect-logo.svg`: horizontal symbol and wordmark lockup for dark surfaces.
- `algo-inspect-logo-light.svg`: the same lockup for light surfaces.
- `../icons/`: generated PNG sizes and the SVG favicon.

Palette: carbon `#0d1117`, blue `#2f81f7`, ice white `#f0f6fc`, and slate `#c9d1d9`.

Regenerate raster icons with `npm run build:icons`. Do not edit the generated PNG files directly.
